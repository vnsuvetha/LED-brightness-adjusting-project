**LED Brightness Adjustment Using a Potentiometer Project**

&nbsp;

**1\. Aim**

The aim is to create a LED brightness adjustment circuit that utilizes a potentiometer. By adjusting the resistance in the potentiometer the brightness of the LED can be modified.

&nbsp;

**2\. Problem Statement**

In illumination circuits the brightness of an LED is typically constant once the power is turned on. This is not convenient if one wants to adjust the level. To address this a potentiometer can be used as a resistor to control the current that flows to the LED, thus varying its brightness.

&nbsp;

**3\. Proposed Solution**

The proposed solution is to create a LED brightness control circuit that incorporates a potentiometer, an LED, a resistor, a battery/DC supply and connecting wires. As the knob on the potentiometer is turned the resistance in the device changes thus controlling the current that reaches the LED.

&nbsp;

**4\. Components Required**

* LED  
* Potentiometer  
* Resistor  
* Battery&nbsp;  
* Breadboard  
* Connecting Wires

&nbsp;

**5\. Circuit Working**

The circuit utilizes the variable resistor capability of the potentiometer. As the knob of the potentiometer is turned the resistance of the device changes, which controls the current that flows to the LED. If the resistance increases the LED current decreases and the LED dims. If the resistance decreases the LED current. The LED brightens. A resistor is added to limit the LED current to prevent it from receiving too much current. This way the circuit provides a method to manually adjust the LED brightness.

&nbsp;

**6\. Procedure**

Follow the mentioned procedure to construct and demonstrate the working of the circuit:

&nbsp;

1\. Place the breadboard on a surface

2\. Insert the LED into the breadboard

3\. Add the resistor in series with the LED

4\. Connect the potentiometer to the circuit

5\. Add the required wires between the LED, resistor and potentiometer

6\. Connect the battery/DC power supply to the circuit

7\. Check that all the connections are secure and correctly connected

8\. Switch ON the power supply

9\. Rotate the potentiometer slowly in one direction

10\. Observe the change in brightness

11\. Rotate the potentiometer in the direction

12\. Observe that the LED brightness changes accordingly

13\. Repeat the adjustment. Record the observations.
